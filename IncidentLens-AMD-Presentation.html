⚡ The Core Problem

LLM gateways can suffer premature SSE termination, retry cascades, and unsafe cache writes. A model asked to triage those traces can also produce plausible explanations that are not tied to any supplied event.

🛡️ The Evidence-Bound Fix

IncidentLens algorithmically parses gateway traces into an indexed evidence matrix ([EVT-001], etc.), sends the bounded bundle to AMD TokenFactory when configured, and enforces a fail-closed citation gate on model responses.

🚀 AMD TokenFactory Adapter

When AMD_API_KEY is configured, the bounded evidence bundle is sent to the event-issued TokenFactory chat-completions endpoint. The public deployment stays in disclosed deterministic evaluation mode.

1️⃣ Deterministic Telemetry Parser

src/trace_parser.mjs parses raw SSE stream transitions, HTTP response codes, and socket lifecycles algorithmically:

  • Flags premature disconnections before [DONE] sentinels.
  • Detects retry storms with delta < 200ms without jitter.
  • Identifies attempted cache writes on truncated streams.
  • Calculates TTFT & latency SLA outlier thresholds.

2️⃣ Bounded Evidence Matrix

src/evidence_matrix.mjs converts parsed events into a stable, inspectable evidence table:

  • Every trace event receives a canonical ID: [EVT-001], [EVT-002].
  • Timestamps, durations, token counts, and error codes are bound.
  • The bounded evidence bundle is dispatched to TokenFactory only when an API key is configured.

3️⃣ Fail-Closed Citation Gate

src/citation_validator.mjs inspects every sentence in the model's incident report before surfacing to SREs:

  • Every root-cause claim must cite a valid [EVT-xxx] ID.
  • Any uncited factual assertion is flagged and rejected.
  • Any unknown event ID not in the evidence matrix causes immediate fail-closed denial.

🖥️ Operator Cockpit Features

  • Preset Scenario Simulators: One-click premature-disconnect, retry-storm, and cache-inconsistency fixtures.
  • Telemetry Waterfall Table: Inspects status codes, socket duration, TTFT, token counts, and anomaly badges.
  • Evidence Matrix Viewer: Interactive display of indexed events with stable event IDs.
  • Citation Verification Badge: Visual confirmation that claim units cite known IDs, or that the response was rejected.

🛡️ Security & Enterprise Hardening

  • Explicit Deployment Modes: Local server binds to 127.0.0.1; the public demo runs a separate no-key serverless evaluation path.
  • Content Security Policy: Strict CSP headers, X-Content-Type-Options: nosniff, X-Frame-Options: DENY.
  • Bounded Input: JSON-only requests are capped at 64 KiB and parsed into a constrained event schema.
  • Zero-Key Fallback: Includes deterministic offline fixtures for instant evaluation without external credentials.
